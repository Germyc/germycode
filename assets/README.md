# GermyCode - Web Assets Kit

Estructura de archivos listos para colocar en `/public/assets/` o `/src/assets/` de tu proyecto web.

## 📁 Archivos incluidos:

### 1. Logotipos Principales
- `logo-horizontal.png` — Logo para barra de navegación con fondo oscuro.
- `logo-horizontal-transparent.png` — Logo horizontal con fondo transparente.
- `logo-horizontal.svg` — Vector escalable para navbar.
- `logo-vertical.png` — Logo centrado principal con fondo oscuro.
- `logo-vertical-transparent.png` — Logo centrado con fondo transparente.
- `logo-vertical.svg` — Vector escalable centrado.

### 2. Isotipo e Iconografía
- `isotype.png` — Isotipo romboidal en alta resolución.
- `isotype-transparent.png` — Isotipo con fondo transparente.
- `isotype.svg` — Vector SVG del isotipo.
- `app-icon.png` — Icono cuadrado con esquinas redondeadas.
- `avatar.png` — Avatar circular para Google Maps, WhatsApp Business y Redes Sociales.

### 3. Favicon & Web App Manifest
- `favicon.ico` — Icono multiresolución para navegadores (16x16, 32x32, 48x48).
- `favicon-16x16.png` & `favicon-32x32.png` — Favicons PNG estándar.
- `apple-touch-icon.png` (180x180 px) — Icono para dispositivos iOS.
- `android-chrome-192x192.png` & `android-chrome-512x512.png` — Iconos PWA y Android.
